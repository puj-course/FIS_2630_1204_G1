# Sugerir el lote que vence primero (FEFO)

Guía para el personal de la farmacia.

## Para qué sirve (HU-152)

Cuando un medicamento tiene varios lotes, conviene dispensar primero el que vence antes. Así se reducen las pérdidas por vencimiento. Esta regla se llama **FEFO** (primero en vencer, primero en salir).

## Cómo usarlo

1. En el panel de inventario, **selecciona un lote** del medicamento en la tabla.
2. Pulsa **Sugerir lote**.
3. La tabla selecciona el lote que conviene dispensar primero.
4. Escribe la cantidad y pulsa **Dispensar medicamento** como siempre.



## Qué lotes se tienen en cuenta

Solo se comparan lotes **del mismo medicamento** que se pueden dispensar:

| Condición | ¿Se sugiere? |
|---|---|
| Disponible, con unidades y sin vencer | Sí |
| Vencido o que vence hoy | No |
| Retenido | No |
| Agotado (0 unidades) | No |

Si dos lotes vencen el mismo día, se sugiere el de menor identificador.

## Mensajes que puedes ver

| Situación | Mensaje |
|---|---|
| No hay lote seleccionado | Selecciona primero un lote de la tabla. |
| El medicamento no tiene lotes aptos | No hay lotes disponibles de este medicamento para dispensar. |
| Ya elegiste el que vence primero | El lote seleccionado ya es el que vence primero. |
| Los filtros esconden el lote sugerido | Te dice cuál es y te pide limpiar los filtros para verlo. |

## Importante

El botón **solo sugiere y selecciona**: no dispensa nada por sí solo.
