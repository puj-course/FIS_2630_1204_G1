# HU-89 — Principios de Usabilidad y Accesibilidad en CareStock

## Principios de usabilidad aplicados

| Principio | Cómo se aplicó | HU relacionada |
|---|---|---|
| Consistencia | Misma paleta y componentes reutilizados en todas las vistas | HU-26, HU-47 |
| Feedback visual inmediato | Mensajes de éxito/error tras cada acción crítica | HU-43 |
| Prevención de errores | Bloqueo visual de fechas no permitidas antes de guardar | HU-45 |
| Reconocimiento sobre recuerdo | Badges de color para identificar rol/farmacia de un vistazo | HU-56, HU-62 |



## Contraste de color (WCAG 2.1 AA)

| Fondo | Texto | Uso |
|---|---|---|
| #FDF5F5 (coral claro) | #7A2E2E (coral oscuro) | Mensajes de error |
| #E9F4F4 (menta claro) | #3A6B6B (menta oscuro) | Mensajes de éxito / badge farmacéutico |
| #FFF9EE (durazno claro) | #854F0B (durazno oscuro) | Advertencias de vencimiento |

Regla general: nunca se usa texto blanco sobre un color pastel claro; siempre se usa una variante oscura del mismo color para garantizar legibilidad.
